# トラブルシューティング

OpenPerch のアプリとエクスポーターが表示するメッセージコードごとに、原因と対処をまとめています。
コードは、エクスポーターのレポートとアプリの診断画面・取り込み結果に表示されます。

- コードの先頭の文字は重大度を表します。`E_` はエラー（処理を止めます）、`W_` は警告（処理は続けます）、`I_` はお知らせです。
- 各節の見出しはコードそのものです。`troubleshooting.md#<コードを小文字にしたもの>`（例: `#e_elevated`）で、その節を直接開けます。
- 取り込みの失敗は、まとめのコード（`E_IMPORT_` で始まるもの）と、理由を表す詳細コード（`E_PKG_`、`E_MANIFEST_`、`E_COMPAT_` で始まるもの）を組み合わせて表示します。

## 安全に使うために

OpenPerch は、読み込むファイルを、自分で書き出したものであっても信頼しない入力として扱い、取り込みのたびに検査します。
それでも、Unity のランタイムやグラフィックスドライバの脆弱性は、アプリ側では防げません。**読み込むのは、自分で書き出したファイルだけにしてください。**

ファイルに記録した CRC-32 と SHA-256 で検出できるのは、コピーや転送の途中で起きた破損だけです。悪意のある改ざんは防げません。

## 権限と取り込み

### E_ELEVATED

管理者として実行されているため、取り込みとロードを無効にしています。

- **原因**: OpenPerch が管理者権限で起動されています。管理者権限のプロセスで信頼しないファイルを読み込むと、脆弱性を突かれたときの影響が大きくなるため、取り込みとロードを止めています。
- **対処**: OpenPerch を終了し、通常の権限で起動し直してください。exe のプロパティの「互換性」で「管理者としてこのプログラムを実行する」が有効になっていれば外してください。

### I_IMPORT_UNTRUSTED_DECLINED

入手元を確認できないファイルの取り込みを取りやめました。

- **原因**: インターネットなどから取得したことを示す印（Mark of the Web）が付いたファイルを取り込もうとし、確認の画面で取り込まないことを選びました。
- **対処**: 取り込むのは自分で書き出したファイルだけにしてください。自分で書き出したファイルを、クラウドストレージなどを経由して移した場合は、もう一度取り込んで確認の画面で取り込むことを選んでください。

### E_IMPORT_COPY_FAILED

ライブラリへのコピーに失敗しました。

- **原因**: 検査の前にファイルをライブラリのフォルダへコピーしますが、そのコピーができませんでした。元のファイルを別のアプリが開いている、読み取りの権限が無い、ライブラリのフォルダに書き込めない、などが考えられます。
- **対処**: 元のファイルを開いているアプリを閉じてから、もう一度取り込んでください。ネットワークドライブやクラウドの同期フォルダにあるファイルは、ローカルのフォルダへコピーしてから取り込んでください。

### E_IMPORT_DISK_FULL

ディスクの空き容量が足りないため、取り込めません。

- **原因**: ライブラリがあるドライブの空き容量が、ファイルのコピーに足りません。
- **対処**: 空き容量を増やしてから、もう一度取り込んでください。使っていないアバターをライブラリから削除しても空きが増えます。

### E_IMPORT_HEADER

パッケージのヘッダが不正なため、取り込めません。

- **原因**: パッケージの先頭にあるヘッダが形式の規則に合いません。一緒に表示される `E_PKG_` で始まる詳細コードが、具体的な理由を示します。
- **対処**: 詳細コードの節を参照してください。多くの場合、ファイルが壊れているか、`.opk` ではないファイルです。

### E_IMPORT_MANIFEST

パッケージの manifest が不正なため、取り込めません。

- **原因**: パッケージに含まれる書き出しの情報（manifest）が規則に合いません。一緒に表示される `E_MANIFEST_` で始まる詳細コードが、具体的な理由を示します。
- **対処**: 詳細コードの節を参照してください。

### E_IMPORT_INCOMPATIBLE

このアプリでは使えないパッケージです。

- **原因**: パッケージは正しく読めましたが、このアプリでは使えません。一緒に表示される `E_COMPAT_` で始まる詳細コードが理由を示します。
- **対処**: 詳細コードの節を参照してください。

### E_IMPORT_SHA256_MISMATCH

バンドルの内容が manifest のハッシュと一致しません。ファイルが壊れています。

- **原因**: バンドル部分の SHA-256 が、manifest に記録された値と一致しません。コピーや転送の途中でファイルが壊れたと考えられます。
- **対処**: 書き出したパソコンから、もう一度ファイルをコピーしてください。直らなければ書き出し直してください。

## パッケージのヘッダ

### E_PKG_BAD_MAGIC

OpenPerch のパッケージ（.opk）ではありません。

- **原因**: ファイルの先頭が `.opk` の識別子ではありません。`.opk` 以外のファイルを選んだか、ファイルの先頭が壊れています。
- **対処**: OpenPerch のエクスポーターで書き出した `.opk` ファイルを選んでください。

### E_PKG_UNSUPPORTED_CONTAINER

このアプリが対応していないコンテナ形式のパッケージです。

- **原因**: ヘッダの containerVersion が 1 ではありません。このアプリより新しいエクスポーターがヘッダの構造を変えたか、ファイルが壊れています。
- **対処**: アプリを最新版に更新してください。最新版でも読めなければ、書き出し直してください。

### E_PKG_BAD_FLAGS

パッケージのヘッダに未対応のフラグがあります。

- **原因**: ヘッダの flags が 0 ではありません。このアプリが知らない機能を使って書き出されたか、ファイルが壊れています。
- **対処**: アプリを最新版に更新してください。直らなければ書き出し直してください。

### E_PKG_BAD_RESERVED

パッケージのヘッダの予約領域が 0 ではありません。

- **原因**: ヘッダの予約領域（reserved0、reserved1）が 0 ではありません。ファイルが壊れているか、このアプリより新しい形式です。
- **対処**: アプリを最新版に更新してください。直らなければ書き出し直してください。

### E_PKG_BAD_HEADER_CRC

パッケージのヘッダが壊れています（CRC が一致しません）。

- **原因**: ヘッダに記録された CRC-32 が、ヘッダの中身と一致しません。ファイルの先頭部分が壊れています。
- **対処**: 書き出したパソコンから、もう一度ファイルをコピーしてください。直らなければ書き出し直してください。

### E_PKG_BAD_MANIFEST_OFFSET

パッケージのヘッダが示す manifest の位置が不正です。

- **原因**: ヘッダが示す manifest の位置が、決められた 64 バイト目ではありません。ファイルが壊れています。
- **対処**: 書き出し直してください。

### E_PKG_OUT_OF_RANGE

パッケージ内のデータの位置または長さが範囲外です。

- **原因**: ヘッダが示す manifest・サムネイル・バンドルのいずれかがファイルの外にはみ出しているか、長さが許容範囲の外です。ファイルが途中で切れている場合にも起こります。
- **対処**: 書き出したパソコンから、もう一度ファイルをコピーしてください。直らなければ書き出し直してください。

### E_PKG_OVERLAP

パッケージ内のデータが重なっているか、並び順が正しくありません。

- **原因**: manifest・サムネイル・バンドルの領域が重なっているか、この順に並んでいません。ファイルが壊れています。
- **対処**: 書き出し直してください。

### E_PKG_MISALIGNED

パッケージ内のバンドルの位置が 4096 バイトの境界にありません。

- **原因**: バンドルの開始位置が 4096 の倍数ではありません。ファイルが壊れているか、OpenPerch のエクスポーター以外で作られたファイルです。
- **対処**: OpenPerch のエクスポーターで書き出し直してください。

### E_PKG_LENGTH_MISMATCH

ファイルの長さがパッケージのヘッダと一致しません。ファイルが途中で切れているか、余分なデータが付いています。

- **原因**: ファイルの長さが、ヘッダが示すバンドルの終わりの位置と一致しません。コピーが途中で止まったか、ファイルの末尾に余分なデータが付いています。
- **対処**: 書き出したパソコンから、もう一度ファイルをコピーしてください。直らなければ書き出し直してください。

### E_PKG_MANIFEST_TOO_LARGE

manifest が上限の 256 KiB を超えています。

- **原因**: ヘッダが示す manifest の長さが、上限の 262,144 バイト（256 KiB）を超えています。通常の書き出しでは上限に届かないため、ファイルが壊れていると考えられます。
- **対処**: 書き出し直してください。

### E_PKG_BAD_THUMBNAIL_FIELDS

パッケージのヘッダのサムネイルの指定が不正です。

- **原因**: ヘッダのサムネイルの位置と長さのうち一方だけが 0 になっているか、サムネイルが 2 MiB を超えています。
- **対処**: 書き出し直してください。

## manifest

### E_MANIFEST_JSON_INVALID

manifest を JSON のオブジェクトとして読めません。

- **原因**: manifest が UTF-8 の JSON として読めないか、全体がオブジェクト（`{ … }`）になっていないか、オブジェクトと配列の入れ子が 32 段を超えています。
- **対処**: 書き出し直してください。manifest を手で編集した場合は、元に戻してください。

### E_MANIFEST_MISSING_FIELD

manifest に必須の項目がありません。

- **原因**: manifest に必須の項目がありません。値が 0 や空の文字列になっている場合も、項目が無いものとして扱います。どの項目かは診断情報に表示します。
- **対処**: 書き出し直してください。

### E_MANIFEST_BAD_EXPORT_ID

manifest の exportId の書式が正しくありません。

- **原因**: exportId が、32 桁の小文字の 16 進数ではありません。
- **対処**: 書き出し直してください。

### E_MANIFEST_BAD_LINEAGE_ID

manifest の lineageId の書式が正しくありません。

- **原因**: lineageId が、32 桁の小文字の 16 進数ではありません。
- **対処**: 書き出し直してください。

### E_MANIFEST_BAD_SHA256

manifest の bundle.sha256 の書式が正しくありません。

- **原因**: bundle.sha256 が、64 桁の小文字の 16 進数ではありません。
- **対処**: 書き出し直してください。

### E_MANIFEST_BUNDLE_NAME_MISMATCH

manifest の bundle.name が exportId と対応していません。

- **原因**: bundle.name が、`op-` に exportId をつなげた名前になっていません。
- **対処**: 書き出し直してください。

### E_MANIFEST_BUNDLE_LENGTH_MISMATCH

manifest の bundle.length がヘッダのバンドルの長さと一致しません。

- **原因**: manifest の bundle.length が、ヘッダに記録されたバンドルの長さと一致しません。
- **対処**: 書き出し直してください。

### E_MANIFEST_KIND_ROOT_MISMATCH

manifest の kind と bundle.rootAsset の組み合わせが正しくありません。

- **原因**: kind と bundle.rootAsset の組み合わせが正しくありません。アバター（`avatar`）なら `definition`、モーション（`motion`）なら `motionpack` でなければなりません。
- **対処**: 書き出し直してください。

### E_MANIFEST_UNKNOWN_KIND

manifest の kind が不明な値です。

- **原因**: kind が `avatar` でも `motion` でもありません。
- **対処**: 書き出し直してください。

### E_MANIFEST_BAD_UNITY_VERSION

manifest の exporter.unityVersion を Unity のバージョンとして読めません。

- **原因**: exporter.unityVersion が、`2022.3.22f1` のような Unity のバージョンの書式ではありません。
- **対処**: 書き出し直してください。

### E_MANIFEST_BAD_EXPORTER_VERSION

manifest の exporter.version が SemVer の形式ではありません。

- **原因**: exporter.version が、`1.0.0` のような SemVer の書式ではありません。
- **対処**: 書き出し直してください。

### E_MANIFEST_NEGATIVE_NUMBER

manifest に負の数値があります。

- **原因**: manifest の数値（バンドルの長さ、統計、モーションの長さなど）に負の値があります。
- **対処**: 書き出し直してください。

### E_MANIFEST_TOO_LONG

manifest の文字列が長さの上限を超えています。

- **原因**: 表示名（displayName）が 128 文字を、書き出し時の警告の詳細（warnings の detail）が 256 文字を超えています。文字数は UTF-16 の単位で数えるため、絵文字などは 1 文字で 2 つ分になることがあります。
- **対処**: アバターの名前を短くしてから、書き出し直してください。

### E_MANIFEST_TOO_MANY

manifest の項目の数が上限を超えています。

- **原因**: 書き出し時の警告（warnings）が 128 件を超えています。
- **対処**: 書き出しレポートの警告の原因を減らしてから、書き出し直してください。

## 互換性

### E_COMPAT_FORMAT_TOO_NEW

このアプリより新しい形式のパッケージです。アプリを更新してください。

- **原因**: このアプリが知らない形式（formatVersion）で書き出されています。
- **対処**: アプリを最新版に更新してください。

### E_COMPAT_SCHEMA_TOO_NEW

このアプリより新しいエクスポーターで書き出されています。アプリを更新してください。

- **原因**: このアプリが知らない runtime の型（runtimeSchemaVersion）を使うエクスポーターで書き出されています。
- **対処**: アプリを最新版に更新してください。エクスポーターとアプリは、同じ時期のリリースを組み合わせてください。

### E_COMPAT_WRONG_TARGET

Windows（StandaloneWindows64）向けに書き出されていません。

- **原因**: Unity のビルドターゲットが Windows（StandaloneWindows64）以外のまま書き出されています。
- **対処**: ビルドターゲットを Windows に切り替えてから、書き出し直してください。エクスポーターの「事前チェック」から切り替えられます。

### E_COMPAT_WRONG_COLOR_SPACE

色空間が Linear ではないプロジェクトから書き出されています。

- **原因**: Project Settings の Color Space が Gamma のプロジェクトから書き出されています。
- **対処**: Project Settings → Player → Other Settings の Color Space を Linear にしてから、書き出し直してください。

### E_COMPAT_DIFFERENT_STREAM

このアプリとは系統の異なる Unity で書き出されています。

- **原因**: このアプリとは系統の異なる Unity（2021.3 や Unity 6 など）で書き出されています。Unity は、系統をまたいだバンドルの読み込みを保証していません。
- **対処**: Unity 2022.3.22f1〜2022.3.62f3 で書き出し直してください。Unity 6 で書き出したファイルを使うには、Unity 6 版のアプリが必要です。

### E_COMPAT_NEWER_THAN_APP

このアプリより新しい Unity で書き出されています。

- **原因**: このアプリが使っている Unity より新しいパッチの Unity で書き出されています。新しいパッチで作ったバンドルは、古いパッチでは正しく読めないことがあります。
- **対処**: アプリを最新版に更新するか、Unity 2022.3.22f1〜2022.3.62f3 で書き出し直してください。

### E_COMPAT_KNOWN_BAD_EXPORTER

不具合が知られているエクスポーターで書き出されています。エクスポーターを更新して書き出し直してください。

- **原因**: 正しく読めないファイルを作る不具合が分かっているエクスポーターのバージョンで書き出されています。不具合ごとのコードが一緒に表示されていれば、その節に詳しい説明があります。
- **対処**: エクスポーターを最新版に更新してから、書き出し直してください。

### W_COMPAT_KNOWN_BAD_EXPORTER

不具合が知られているエクスポーターで書き出されています。表示がおかしい場合は、エクスポーターを更新して書き出し直してください。

- **原因**: 不具合が知られているエクスポーターのバージョンで書き出されています。読み込みはできますが、一部が正しく再現されないことがあります。不具合ごとのコードが一緒に表示されていれば、その節に詳しい説明があります。
- **対処**: 表示や動きがおかしい場合は、エクスポーターを最新版に更新してから書き出し直してください。

### W_COMPAT_LEGACY_STREAM_ACCEPTED

Unity 2022.3 で書き出されたパッケージを、Unity 6 版のアプリで読み込みます。

- **原因**: Unity 2022.3 で書き出したファイルを、Unity 6 版のアプリで読み込んでいます。この組み合わせは読み込めることを確かめていますが、同じ系統どうしの組み合わせほどは検証していません。
- **対処**: 問題がなければ、そのまま使えます。表示がおかしい場合は、Unity 6 で書き出し直すか、Unity 2022.3 版のアプリを使ってください。

## サムネイル

### W_THUMB_REJECTED

サムネイルが条件を満たさないため、表示しません。

- **原因**: サムネイルの PNG が条件（幅と高さが 512 以下、1 チャンネル 8 ビット、RGB か RGBA、インターレースなし）を満たしません。大きすぎる画像の展開でメモリを使い果たさないよう、画像を開く前に判定しています。
- **対処**: アバターはそのまま使えます。サムネイルが必要なら、書き出し直してください。

## ロードと表示

### E_LOAD_CRC

バンドルの CRC が一致しません。ファイルが壊れています。

- **原因**: 初めてのロードで、バンドルの CRC が manifest の値と一致しませんでした。取り込んだ後に、ライブラリの中のファイルが壊れたと考えられます。
- **対処**: ライブラリから削除し、もう一度取り込んでください。

### E_LOAD_DEFINITION_MISSING

パッケージにアバターまたはモーションの定義が含まれていません。

- **原因**: バンドルの中に、アバターの定義（`definition`）またはモーションパック（`motionpack`）がありません。
- **対処**: 書き出し直してください。

### E_LOAD_EXPORT_ID_MISMATCH

パッケージの中身が manifest の exportId と一致しません。

- **原因**: バンドルの中の定義に記録された exportId が、manifest の exportId と一致しません。別の書き出しのバンドルが入っています。
- **対処**: 書き出し直してください。

### E_LOAD_BUNDLE_NAME_COLLISION

同じ名前のバンドルがすでに読み込まれています。

- **原因**: 読み込もうとしたバンドルと同じ名前のバンドルが、すでにアプリに読み込まれています。Unity は同じ名前のバンドルを同時に読み込めません。
- **対処**: アプリを再起動してから、もう一度表示してください。直らなければ、同じ書き出しを別のファイルとして重複して取り込んでいないか、ライブラリを確認してください。

### E_DEF_INVALID

アバターまたはモーションの定義の構造が不正なため、読み込めません。

- **原因**: アバターの定義かモーションパックの構造が規則に違反しています。メニューの参照先が範囲の外にある、身長が 0.2〜5 m の外にある、件数が上限を超えている、などです。
- **対処**: エクスポーターを最新版に更新してから、書き出し直してください。

### E_LOAD_SANITIZE_REJECTED

安全のための検査で拒否されたため、表示できません。

- **原因**: 表示する前の安全のための検査で、許可していないコンポーネントを取り除けなかったなどの理由で、表示を拒否しました。
- **対処**: エクスポーターを最新版に更新してから、書き出し直してください。書き出しレポートに除去されたコンポーネントが出ていれば、元のアバターから取り除くと解決する場合があります。

### W_DEF_CLAMPED

許容範囲外の値を範囲内に収めました。揺れ方や見た目が書き出し元と異なることがあります。

- **原因**: 揺れもの・Constraint・パラメータなどの値が許容範囲の外にあったため、範囲の端の値に置き換えました。
- **対処**: 見た目や揺れ方が気になる場合は、元のアバターで該当する値を見直してから、書き出し直してください。

### W_REF_OUTSIDE

アバターの外を指す参照を外しました。該当する揺れものや Constraint は動きません。

- **原因**: 揺れものや Constraint などの参照が、アバターの外にあるオブジェクトを指していました。安全のために参照を外し、根元や対象を失ったコンポーネントは動かさないようにしました。
- **対処**: 元のアバターで、参照がアバターの中のボーンを指すように直してから、書き出し直してください。

### W_REMOVED_COMPONENT

OpenPerch で扱えないコンポーネントを除去しました。

- **原因**: OpenPerch が扱わない種類のコンポーネント（音声や、未知のスクリプトなど）が含まれていたため、除去しました。除去した種類と数は詳細に表示します。
- **対処**: 除去したコンポーネントは OpenPerch では動きません。表示に問題がなければ、そのまま使えます。

## エクスポーター

### W_EXPORT_UNITY6_APP_ONLY

Unity 6 で書き出したファイルは、Unity 6 版のアプリでのみ読めます。

- **原因**: Unity 6（6000.x）で書き出しています。Unity 6 で作ったバンドルは、Unity 2022.3 版のアプリでは読めません。
- **対処**: Unity 6 版のアプリで使う場合は、そのまま続けてください。Unity 2022.3 版のアプリで使う場合は、Unity 2022.3.22f1〜2022.3.62f3 で書き出してください。

### E_EXPORT_UNSUPPORTED_UNITY

この Unity のバージョンでは書き出せません。Unity 2022.3.22f1〜2022.3.62f3 で書き出してください。

- **原因**: エクスポーターが対応していない Unity で実行しています。対応しているのは 2022.3.22f1〜2022.3.62f3 と、Unity 6（6000.x）です。
- **対処**: VRChat が指定している Unity 2022.3.22f1 で書き出してください。
